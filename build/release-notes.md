## Glassy 0.2.15

**Glassy now runs on Mac.** It uses the system's own window buttons and blur, and the ⌘ key for shortcuts.

**Change a cover everywhere.** Editing a cover now shows every other song with that exact picture, and one switch changes them all at once.

**Covers in the media pop-up.** The volume and lock-screen pop-up now gets the song's cover.

Installed copies on Windows update themselves. New install:

- **Windows:** `Glassy-Setup-0.2.15.exe`
- **Mac with Apple silicon (M1 or newer):** `Glassy-0.2.15-mac-arm64.dmg`
- **Mac with an Intel chip:** `Glassy-0.2.15-mac-x64.dmg`

The Mac files appear here a few minutes after the Windows ones. Glassy isn't signed with an Apple developer account yet, so the first time you open it on a Mac, go to System Settings → Privacy & Security and click Open Anyway. The [README](https://github.com/pxlarized2/glass-player#opening-it-on-a-mac-for-the-first-time) has the steps.
