## Glassy 0.2.17

**Steadier glass edges on Windows.** This is aimed at the strip that could flicker along the bottom of the panels while lyrics play. Tell us if you still see it, or if big windows feel less smooth.

Installed copies on Windows update themselves. New install:

- **Windows:** `Glassy-Setup-0.2.17.exe`
- **Mac with Apple silicon (M1 or newer):** `Glassy-0.2.17-mac-arm64.dmg`
- **Mac with an Intel chip:** `Glassy-0.2.17-mac-x64.dmg`

The Mac files appear here a few minutes after the Windows ones. Glassy isn't signed with an Apple developer account yet, so the first time you open it on a Mac, go to System Settings → Privacy & Security and click Open Anyway. The [README](https://github.com/fentdevelops/glass-player#opening-it-on-a-mac-for-the-first-time) has the steps.
